# ARTIVO — Product & Development Specification

## 1. VISIÓN DEL PRODUCTO

ARTIVO es una plataforma digital de contratación de talento artístico bajo demanda.

Conceptualmente combina:

- Instagram/TikTok para descubrir artistas.
- Uber/PedidosYa para solicitar y contratar talento.
- Marketplace para conectar clientes con artistas.
- Agenda profesional para artistas.
- Wallet/cartera para controlar ingresos.
- Control de gastos y ganancias.
- Sistema de reputación y reviews.
- Herramientas profesionales para artistas.
- Herramientas Business para hoteles, restaurantes, agencias y empresas.

La idea central es:

> "Pide un artista como pides un delivery."

ARTIVO no debe limitarse a ser una red social de músicos.

Debe convertirse en una infraestructura para contratar y administrar talento artístico.

El primer mercado objetivo es música y entretenimiento en vivo:

- DJs
- Pianistas
- Cantantes
- Saxofonistas
- Violinistas
- Guitarristas
- Percusionistas
- Bandas
- Instrumentistas
- MCs
- Animadores
- Performers

En el futuro puede ampliarse a:

- Bailarines
- Actores
- Fotógrafos
- Videógrafos
- Presentadores
- Magos
- Comediantes
- Otros profesionales creativos

# 2. PROPUESTA DE VALOR

## Para clientes

Un cliente puede encontrar, comparar, reservar y pagar a un artista desde una sola plataforma.

Ejemplo:

Un restaurante en Punta Cana necesita un saxofonista.

El cliente entra a ARTIVO:

1. Selecciona "Saxofonista".
2. Selecciona ubicación.
3. Selecciona fecha.
4. Selecciona hora.
5. Selecciona duración.
6. Introduce presupuesto.
7. ARTIVO muestra artistas disponibles.
8. El cliente compara:
   - videos
   - precio
   - distancia
   - rating
   - experiencia
   - disponibilidad
   - equipo
9. El cliente selecciona un artista.
10. Envía una solicitud.
11. El artista acepta.
12. El cliente paga.
13. Se confirma el booking.
14. Se realiza el servicio.
15. El cliente confirma finalización.
16. El artista recibe el dinero.
17. Ambos pueden calificarse.
